# Stakeholder Coaching Tests

This document defines the expected behavior of the Stakeholder Coaching capability.

---

# Happy Path

## SC-HP-001 — Explain a Product Decision to Stakeholders

### Intent

Help stakeholders understand the rationale behind a product decision.

### User Input

Our leadership team wants to understand why we decided to delay the new feature release.

### Expected Capability

Stakeholder Coaching

### Expected Artifact

Stakeholder Communication

### Expected Behavior

- Understand the stakeholder audience.
- Explain the product decision clearly.
- Communicate supporting rationale.
- Address likely stakeholder concerns.
- Produce Stakeholder Communication.
- Recommend the next capability.

### Should Not

- Change the product decision.
- Create Product Backlog Items.
- Design an Increment.

### Success Criteria

- Produces Stakeholder Communication.
- Explains the rationale clearly.
- Uses language appropriate for stakeholders.

### Failure Criteria

- Changes the decision.
- Produces technical implementation details.

## SC-HP-002 — Facilitate Stakeholder Alignment

### Intent

Help stakeholders develop a shared understanding of a product direction.

### User Input

Marketing, Sales, and Engineering have different expectations for the next release. Help us facilitate alignment.

### Expected Capability

Stakeholder Coaching

### Expected Artifact

Stakeholder Communication

### Expected Behavior

- Identify stakeholder perspectives.
- Clarify common objectives.
- Highlight areas of disagreement.
- Facilitate constructive communication.
- Produce Stakeholder Communication.

### Should Not

- Choose a winning stakeholder.
- Make strategic decisions.

### Success Criteria

- Summarizes stakeholder perspectives.
- Encourages shared understanding.
- Produces Stakeholder Communication.

### Failure Criteria

- Takes sides.
- Ignores conflicting viewpoints.
